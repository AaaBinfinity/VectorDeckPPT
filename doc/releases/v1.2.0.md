# VectorDeckPPT v1.2.0

VectorDeckPPT v1.2 turns the presentation workflow into a more deliberate collaboration: the Agent confirms the complete brief and visual source before production, then uses richer content, exact typography roles, and inspectable multi-page template families to create editable PowerPoint deliverables.

## Highlights

- Requires an explicit request contract before source synthesis, including audience identity, knowledge and decision authority, outcome, evidence boundaries, presentation setting, visual source, editability, deliverables, and output location.
- Adds a visual-source decision: choose a bundled family, upload a PPT/PPTX/PDF/image/screenshot/brand reference, approve a hybrid of at most two sources, or explicitly delegate selection to the Agent.
- Expands the library to twelve visual families. Every family now has its own directory, an overview, and ten full-size SVG/PNG reference pages covering cover, section, narrative, context, process, evidence, comparison, roadmap, decision, and close.
- Adds Forest Poetic Mosaic, Silk & Ink Strategy, and Museum Cultural Editorial for expressive cultural work with scoped calligraphic display typography.
- Adds a deterministic typography audit for exact deck-wide slide-title tokens and same-page peer roles.

## Content and visual quality

- Substantive slides now default to a complete claim, explanation, concrete evidence or example, and an implication or action.
- When sources permit, roughly two thirds of core pages use a meaningful chart, diagram, table, process, matrix, or annotated image; the workflow still forbids invented numbers and decorative pseudo-data.
- Artistic display fonts are restricted to named hero roles such as `deck-title` and `section-title`. Ordinary slide titles, evidence, labels, and body text remain readable and consistent.
- Professional work may use controlled asymmetry, crop, overlap, arcs, diagonals, and scale contrast without becoming a rigid card grid or an unrestrained poster.

## Documentation and assets

- Redesigns the README around real generated previews, a faster quick start, capability boundaries, and role-based documentation links.
- Adds a task-oriented usage guide, reusable prompt examples, a contributor guide, and a role-based documentation index.
- Synchronizes the PRD, Skill references, template catalog, troubleshooting guidance, release metadata, and project-introduction example with V1.2 behavior.

## Quality

- More than 70 automated tests cover parsing, validation, rendering, editable compilation, typography, dependencies, documentation, release metadata, path safety, and end-to-end delivery.
- All 132 bundled template SVGs validate, and every family passes the strict typography audit.
- The tracked project-introduction deck compiles to 748 native PowerPoint objects with zero embedded SVG fallbacks and zero failures.

## Upgrade notes

- Existing prompts should add a visual-source choice or explicitly delegate style selection; when no source is provided, the Agent will present exactly three suitable candidates before work begins.
- Bundled template paths changed from flat files to `assets/style-templates/<family>/overview.*` and `assets/style-templates/<family>/slides/`.
- Existing Decks remain compatible. Re-run the current typography audit before recompiling if their ordinary slide titles or same-page peer headings were authored with inconsistent tokens.
