# VectorDeckPPT v1.1.0

VectorDeckPPT v1.1 makes the vector-first presentation workflow safer, more editable, and easier to use from either a repository checkout or a global Skill installation.

## Highlights

- Adds mandatory text-content and representative visual-sample approval gates before full deck production.
- Adds five bundled 16:9 art-direction references and richer evidence-led default slide planning.
- Adds editable PowerPoint freeform conversion for straight-segment SVG `polygon` and `polyline` elements.
- Adds standard `pip install -r requirements.txt` support alongside uv.
- Adds explicit `SKILL_ROOT` and `DECK_ROOT` resolution, with `./pptoutput/` as the default delivery root.

## Reliability fixes

- Corrects SVG font-size conversion to follow the same viewBox scale as slide geometry.
- Rejects PNG, PPTX, and JSON output paths that use the wrong extension or alias an input/source file.
- Removes pretty-print-only tspan whitespace while honoring `xml:space="preserve"`.
- Preserves supported SVG line caps and joins in native PowerPoint shapes.
- Uses Office SVG fallback for unsupported baselines, dashed strokes, markers, clipping, paint servers, rotation, and skew instead of silently changing appearance.

## Quality

- 65 automated tests cover validation, rendering, editable compilation, freeforms, path safety, font scaling, text handling, release metadata, dependencies, Skill structure, and end-to-end delivery.
- Both tracked example decks were recompiled with the V1.1 compiler and pass PPTX package validation.

## Upgrade notes

- Existing generated PPTX files should be recompiled to receive the corrected font scaling.
- The Skill now requires separate explicit approval of the full text-only slide draft and the representative visual sample before it produces the complete deck.
